# Abhiram Jampani — Portfolio

Personal portfolio with a Game of Thrones–inspired look: House Stark (frost) and House Targaryen (fire) themes, a procedural 3D dragon egg, and smooth scroll-driven animation.

**Stack:** Next.js · TypeScript · Tailwind CSS · React Three Fiber · GSAP ScrollTrigger · Lenis

```bash
npm install
npm run dev     # http://localhost:3000
```

All text content lives in `src/data/content.ts`.
